# YouTube Video Summarizer AI

An AI-powered web application that summarizes long YouTube videos into concise and easy-to-read notes using Google Gemini.

## Project Overview

This project helps students, professionals, and tech enthusiasts quickly understand lengthy YouTube videos without watching the entire content. It extracts the video transcript, identifies the important information, and generates a concise summary using AI.

## Features

- Automatic YouTube transcript extraction
- AI-generated concise summaries
- Video thumbnail preview
- Simple and user-friendly interface
- Fast and lightweight application

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- youtube-transcript-api
- python-dotenv

## Project Architecture

YouTube URL → Transcript Extraction → Gemini AI → Summary Generation → Streamlit Interface
